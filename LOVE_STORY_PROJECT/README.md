# «Атлас одной любви»: исходники книги

Это пример книги с вымышленной историей. Его можно превратить в вашу книгу.

## Как сделать книгу своей
1. **Фото:** положите снимки в `photos/` под именами `photo-01.jpg` … `photo-14.jpg`. Что куда — в `photos/ПОДСКАЗКИ.md`.
2. **Текст:** правьте `content/book.md`. Это обычный текст с блоками `::: {.класс}`. Имена удобно менять поиском с заменой («Вера», «Марк», «В.», «М.»).
3. **Сборка:** `python3 tools/build.py`. Все форматы появятся в `../LOVE_STORY_FINAL`.

Нужны: `pandoc`, Python-пакеты `weasyprint pymupdf python-docx pillow`. Для HEIC-фото дополнительно нужен `pillow-heif`.

## Блоки разметки
| Блок | Что делает |
|---|---|
| `# Название {#id .chapter label="Глава…" plate="plate-01" fig="…"}` | Разворот-открытие главы с иллюстрацией |
| `::: {.quotepage}` | Страница с крупной цитатой |
| `::: {.photo slot="NN" layout="frame" orient="portrait|landscape"}` | Фото в рамке с подписью |
| `::: {.pair slots="NN,MM"}` | Два фото рядом |
| `::: {.bleed slot="NN"}` | Фото на всю страницу «в обрез» |
| `::: {.letter}`, `{.messages}`, `{.notes}` | Письмо, переписка, дневниковые записи |
| `::: {.songnote}` | Место для слов вашей песни |
| `::: {.poem}` с строками `| …` | Стихотворение |

## Структура
- `content/`: рукопись, варианты названия, рабочая хронология
- `design/philosophy.md`: визуальная концепция «Шёлковая картография»
- `art/`: иллюстрации, сгенерированы `tools/plates.py`; SVG — вектор для печати, PNG — для EPUB и DOCX
- `fonts/`: EB Garamond, Cormorant Garamond, Cormorant SC (лицензия SIL OFL 1.1, кириллица)
- `tools/`: сборка (`build.py`), фильтр Pandoc (`book.lua`), стили (`css/`), стили Word (`make_reference.py`), превью страниц (`preview.py`)
